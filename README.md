# Case Converter Toolkit — V3

## Features
- Six formats: kebab-case, camelCase, PascalCase, snake_case, SCREAMING_SNAKE_CASE, Title Case
- Bulk line-by-line conversion
- Copy individual results or all results
- Dark/light theme with saved preference
- Settings for accented characters, numbers, and special characters
- Conversion history with search, restore, delete, clear (up to 50 entries)
- Export results as TXT or JSON
- Keyboard shortcuts: Ctrl+Enter saves history, Ctrl+Shift+C copies kebab-case, Esc clears input
- No backend or database

## Run
Extract the ZIP and open `kebab-case-converter/index.html` in a modern browser. Tailwind CSS and Alpine.js load from CDNs, so internet access is needed.

Theme preference and conversion history are stored in the current browser's localStorage.
